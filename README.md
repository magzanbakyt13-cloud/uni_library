# UNI Library — Университет кітапхана жүйесі

Веб-приложение для автоматизации работы университетской библиотеки, разработанное на базе **Python** и **Flask**. Проект реализует полный функционал учета книг, авторов, читателей и выдачи литературы.

## 🛠 Технологический стек
* **Язык программирования:** Python 3.x
* **Веб-фреймворк:** Flask, Flask-SQLAlchemy, Flask-Login, Flask-WTF
* **База данных:** SQLite
* **Интерфейс:** Bootstrap 5, Jinja2[cite: 12]

---

## 👥 Роли в системе
1. **Администратор (Admin):** Имеет полный доступ к управлению книгами, авторами, пользователями и мониторингу всех выдач.
2. **Пользователь (User):** Может просматривать каталог книг, брать книги во временное пользование и отслеживать свои активные займы.

---

## 📦 Модели данных (SQLAlchemy)
В системе реализованы 4 взаимосвязанные модели[cite: 12]:
* **User:** Пользователи системы (с разделением ролей на `admin` и `user`).
* **Author:** Авторы книг (связь 1-к-многим с книгами).
* **Book:** Книги в библиотеке (информация о наличии, ISBN, обложках).
* **Loan:** Выдача книг читателям (учет сроков возврата и проверка просрочки).
